# LFG Region

Shows compact realm-region badges for leaders and applicants in the World of Warcraft Premade Groups interface.

## Features

- Region badge on every supported group leader in Find a Group
- Region badge on every supported applicant in Start a Group
- Account-wide toggles for either view
- Compatibility API for addons that used the original `PremadeRegions` WeakAura global
- No libraries or configuration addon required

## Usage

The addon works automatically after login. Use `/lfgr` for commands.

LFG Region supports the Americas game region. Listings from unknown realms are left unmarked.
